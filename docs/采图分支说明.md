# A/B 人物识别原图采集分支

分支：`codex/person-raw-capture`，基于已加入 A 识别后前进约 5 厘米的主干。

此分支仅在 YOLO 节点增加采图功能。每次 `detect_flag=1`（A）和 `detect_flag=2`（B）的 YOLO 推理完成后，分别保存本次推理使用的 `/image_raw` 无标注原图和相应的带框图。两个文件使用同一时间戳文件名，分别以 `_raw.png` 和 `_detected.png` 结尾，避免后一次运行覆盖前一次素材。默认输出目录：`~/smart_ws/person_samples/`。启动人物节点时可用 `capture_dir:=/你选择的绝对路径` 修改目录。

在虚拟机切换到该分支后，人物节点仍按原命令启动：

```bash
source ~/smart_ws/devel/setup.bash
roslaunch yolo_ros yolo.launch input_image_topic:=/image_raw
```

两路口任务仍用 `roslaunch robot_navigation two_intersection_mission.launch` 启动。两次识别都成功后，可在虚拟机运行 `ls -lh ~/smart_ws/person_samples/` 查看 A/B 原图和带框图。保存失败时识别服务返回错误，任务会停车，避免误以为素材已采集。此分支的采图逻辑未合入 `main`。
