# 两路口任务一键启动

本入口面向现有虚拟机 `~/smart_ws/src/smart_community`。它依次启动 Gazebo 和小车、导航与 RViz、红绿灯识别、人物 YOLO v4，以及两路口任务。各阶段会等待相机、地图、导航、定位变换和识别服务就绪。最终到第二处路口后面向车牌停车；本阶段不识别车牌。

先关闭之前手动开启的 Gazebo、导航、红绿灯和 YOLO 终端，确认小车初始位置在第一处停止点之前。更新代码后执行一条命令：

```bash
cd ~/smart_ws/src/smart_community
bash tools/start_two_intersection.sh
```

运行期间保留该终端。任务结束后 Gazebo 和 RViz 保持打开，以便查看最终位置；按 `Ctrl+C` 关闭整套仿真。脚本使用 `robot_navigation/map/map_portable.yaml`、`yolo_ros/weights/person_v4.pt` 和当前虚拟机的 `robot_simulation/world/competition.world`，不覆盖虚拟机中已调好的场景文件。

**启动边界：** Git 仓库现有 `competition.world` 仍是旧场景；虚拟机中当前场景已由用户确认正常。脚本会检查世界文件是否包含灯和人物模型，缺失则拒绝启动。仓库中的完整比赛场景及模型素材仍需单独同步，才能在全新虚拟机上复现。脚本在 Windows 上只做语法和静态检查；Gazebo/ROS 启动与路线安全须在当前虚拟机验证。
