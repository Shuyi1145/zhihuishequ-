## 五、提交前必须核对的差异

1. `2026开源资料/robot_simulation/` 已并入 Git `robot_simulation/`；用户确认虚拟机使用这一场景来源，但更新后的 Git 版本尚未在虚拟机重新编译运行。
2. Git 的 `robot_navigation/map/map.yaml` 已改为相对路径 `map.pgm`。虚拟机若对该文件有未提交的本地修改，拉取前要先查看 `git status --short` 并保留自己的改动。
3. Git 的 `robot_navigation/config/baidu_ocr.env` 被跟踪。报告、截图和提交包不应展示实际密钥；建议以示例配置和部署时注入代替，并轮换已公开的密钥。
4. 本机未发现最终 `.mp4`、ROS bag 或最新整圈日志。阶段记录最后确认的是 A 后短距离前进失败，之后用户称“差不多完赛”，但缺少可独立核查的终点与三车牌运行证据。
5. A/B 服务当前按观察画面分别计数，代码没有跨画面的身份去重。若两画面有重叠，不能直接把两次数字相加为全街区唯一人数。
6. 技术报告模板要求源码 ZIP 不超过 150 MB，视频 MP4 不超过 300 MB，并建议 8–12 分钟。`person_training/` 本机约 272 MB，历史 bundle、虚拟机镜像和多轮权重不应直接整体塞进源码包；提交包只纳入实际复现所需的最终模型、地图、场景、源代码和 README。
